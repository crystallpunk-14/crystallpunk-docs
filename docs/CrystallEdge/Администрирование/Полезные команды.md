# Полезные команды

Пока что неотсортированный список команд, нужных и полезных для работы администратора сервера.
По мере добавления сюда информации, список будет сортироваться и структурироваться.


- `znetwork-weather` Включение или выключение погоды на всех з-уровнях одной сети одновременно.

- `changecvar game.closed_beta_test False\True` Включает или отключает ограничение на запуск сервера (когда включен, играть можно только по графику)
