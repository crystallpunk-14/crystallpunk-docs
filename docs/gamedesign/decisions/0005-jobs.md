# Профессии должны предоставлять способ заработка

## Контекст

Профессии на которых невозможно получать деньги стабильно играются плохо, игроки на них ощущают себя скованными в возможностях.

## Решение

Все профессии должны иметь стабильные способы заработка денег связанные с их деятельностью.
