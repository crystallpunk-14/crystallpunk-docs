# Реактивность и проактивность профессий

Геймплей каждого отдела\профессии должен сочетать 2 части.

## Проактивность

Действия, выполняемые игроками для достижения целей.

Примеры:
- Постройка инженерной фабрики для автоматизации добычи ресурсов.
- Экспедиции во мрак за артефактами.

## Реактивность

Действия, которые выполняются как реакции на события в игре.

Примеры:
- Починка поломанных труб или построек
- Кормление голодных клиентов
- Лечение раненных
