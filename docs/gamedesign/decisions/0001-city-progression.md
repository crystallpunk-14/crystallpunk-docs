# Прогрессия силы для города

## Контекст

В рамках сессий на 1-2 часа, механики прогрессии превращаются в "Сизифов труд", заставляя игроков выполнять одни и те же инструкции, результат которых сбрасывается в конце раунда.

## Решение

Механики прогрессии силы для города, разрешены только в направлении выполнения цели города.
