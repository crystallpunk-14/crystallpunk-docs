# <Краткое описание решения>

Номер ADR — это префикс имени файла (0007-название.md → #0007), отдельно
записывать его никуда не нужно. Статус ("Принято" / "Заменено") считается
автоматически: пока ни один другой ADR не указал этот номер в своём
`supersedes`, решение считается принятым.

## Контекст
Ситуация, из-за которой было принято это решение. Это может быть результат плейтестов, какая-то проблема в геймплее или другой источник давления.
2-5 предложений, только описание ситуации.

## Decision
Принятое решение, описанное одним предложением.
Например:
- После смерти игрок в течение минуты может получить нового персонажа.
